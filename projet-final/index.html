Projet final — CRM SaaS

Ce projet final consiste à développer une application CRM web permettant de gérer les contacts, entreprises, opportunités commerciales, tâches et campagnes d’emailing dans une architecture moderne full SaaS.

Next.js React Django API REST PostgreSQL Vercel
Code source Live demo Rapport

Présentation du projet

L’objectif du CRM est de centraliser les informations commerciales et de faciliter le suivi des clients, des prospects et des actions à mener.

Fonctionnalités principales

  • Authentification utilisateur
  • Gestion des contacts
  • Gestion des entreprises
  • Gestion des deals / pipeline commercial
  • Gestion des tâches
  • Page emailing
  • Dashboard avec statistiques

Technologies utilisées

  • Frontend : Next.js / React / TypeScript
  • Backend : Django / Django REST Framework
  • Base de données : PostgreSQL ou SQLite en développement
  • Déploiement : Vercel pour le frontend
  • Versionnage : Git / GitHub
